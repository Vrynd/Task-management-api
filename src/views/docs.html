Taskly API Developer Portal

Dokumentasi REST API Task Management - Menyediakan rute lengkap untuk autentikasi, manajemen tugas, sub-tugas, kategori, dan dashboard fokus harian untuk integrasi aplikasi Flutter

API Server: Running
Database: Neon PostgreSQL
Base URL: http://localhost:3000

Getting Started & Konfigurasi Flutter

Panduan ringkas otentikasi keamanan dan integrasi data dengan aplikasi Flutter Anda.

Autentikasi Header
Semua rute yang berlabel Auth Required wajib mengirimkan token JWT yang didapatkan dari proses Login/Register pada header request Anda: 
Authorization: Bearer <TOKEN_JWT_ANDA>
Format Respons API (JSON)
REST API ini menggunakan standarisasi format respons yang konsisten untuk mempermudah pembuatan model di Dart/Flutter:
Respons Sukses 
{
  "success": true,
  "message": "Pesan sukses operasi",
  "data": { ... } // Objek atau Array data
}
Respons Error / Gagal 
{
  "success": false,
  "message": "Detail pesan error",
  "errors": [ ... ] // Rincian validasi (opsional)
}
Daftar Kode Status HTTP
Status Deskripsi Skenario / Kasus
200 / 201 OK / Created Permintaan sukses diproses atau data baru berhasil disimpan.
400 Bad Request Kegagalan validasi input (Zod) atau format JSON tidak sesuai.
401 Unauthorized Token JWT tidak valid, tidak disertakan di header, atau sudah logout.
404 Not Found Data tidak ditemukan atau pengguna tidak memiliki hak kepemilikan.
429 Too Many Requests Terkena pembatasan keamanan rate limiting server (DoS prevention).

1. Authentication Module

Mengelola registrasi pengguna baru, sesi masuk, dan penghancuran token sesi (logout).

POST /api/auth/register Mendaftar akun baru No Auth
Request Body (JSON)
{
  "name": "Rian Wijaya",
  "email": "rian.wijaya@example.com",
  "password": "SandiRahasia123!", // Minimal 6 karakter
  "avatar_url": "https://example.com/avatar.png" // Opsional
}
Response Sukses (201 Created)
{
  "success": true,
  "message": "User registered successfully",
  "data": {
    "user": {
      "id": "a9b1c2d3-...",
      "name": "Rian Wijaya",
      "email": "rian.wijaya@example.com",
      "avatar_url": "https://example.com/avatar.png",
      "created_at": "2026-05-24T06:23:13.000Z",
      "updated_at": "2026-05-24T06:23:13.000Z"
    },
    "token": "eyJhbGciOiJIUzI1NiIsIn..."
  }
}
POST /api/auth/login Masuk sesi akun No Auth
Request Body (JSON)
{
  "email": "rian.wijaya@example.com",
  "password": "SandiRahasia123!"
}
Response Sukses (200 OK)
{
  "success": true,
  "message": "Login successful",
  "data": {
    "user": {
      "id": "a9b1c2d3-...",
      "name": "Rian Wijaya",
      "email": "rian.wijaya@example.com",
      "avatar_url": "https://example.com/avatar.png",
      "created_at": "2026-05-24T06:23:13.000Z"
    },
    "token": "eyJhbGciOiJIUzI1NiIsIn..."
  }
}
POST /api/auth/logout Keluar sesi akun (Blacklist Token) Auth Required
Response Sukses (200 OK)
{
  "success": true,
  "message": "Logout successful"
}

2. Users Module

Mengelola profil pengguna, melacak statistik penyelesaian tugas, dan melacak riwayat log aktivitas pengguna.

GET /api/users/profile Mengambil data profil pengguna Auth Required
Response Sukses (200 OK)
{
  "success": true,
  "message": "User profile retrieved successfully",
  "data": {
    "id": "a9b1c2d3-...",
    "name": "Rian Wijaya",
    "email": "rian.wijaya@example.com",
    "avatar_url": "https://example.com/avatar.png",
    "created_at": "2026-05-24T06:23:13.000Z"
  }
}
PUT /api/users/profile Mengubah data profil pengguna (nama, sandi, atau avatar) Auth Required
Request Body (JSON - Semua opsional) 
{
  "name": "Rian Wijaya Edit",
  "password": "PasswordBaru123",
  "avatar_url": "https://example.com/avatar-new.png"
}
Response Sukses (200 OK)
{
  "success": true,
  "message": "Profile updated successfully",
  "data": {
    "id": "a9b1c2d3-...",
    "name": "Rian Wijaya Edit",
